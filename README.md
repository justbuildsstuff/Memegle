# Memegle

**Google for memes.** Search your meme collection by what is in the picture and what it says,
in a UI that looks and behaves like Google Search. Everything runs in the browser: no server,
no database, no accounts.

Live preview: **https://justbuildsstuff.github.io/Memegle/**

Memegle is a static rebuild of [Meme Search](https://github.com/meme-search/meme-search) by
neonwatty (Apache-2.0). Same feature set, different shape: the Rails + Postgres + Python stack
became a JSON index, IndexedDB and Transformers.js, so it can be hosted on GitHub Pages.

## Features

| Meme Search (upstream) | Memegle |
|---|---|
| Image-to-text models (Florence-2, SmolVLM, Moondream) | Florence-2 base/large running in the browser via Transformers.js (WebGPU or WASM), or any OpenAI-compatible vision API |
| Auto-generate descriptions, bulk generation | "Generate description" per meme, bulk generation from the Images tab (Select), auto-generate on upload |
| Manual description editing | Editable description and image text in the detail panel |
| Tags | Create, assign, rename, delete tags; tag chips filter results |
| Keyword + vector search (pgvector) | BM25 keyword search with prefix matching and "Showing results for" spelling correction; vector search with all-MiniLM-L6-v2 embeddings and cosine ranking |
| Directory paths, filters | Folders tab, folder filter, tag filters, sort by relevance or newest |
| Directory rescan | `python tools/build_index.py` rebuilds the bundled index; Settings > Rescan restores hidden bundled memes |
| Drag-and-drop upload, clipboard paste | Drop anywhere, paste anywhere, or use the Upload page (up to 50 files, JPG/PNG/WEBP/GIF); stored in IndexedDB |
| Dark mode | System, light or dark theme |
| Search API + CLI | URL search: `?q=...` or `#/search?q=...&tab=images&tags=cat|dog&folder=work&mode=vector` |

Google-isms on top: autocomplete with recent searches, tags and memes; "I'm Feeling Memey";
Memegle Lens (pick an image, it gets described and searched); voice search where the browser
supports it; Images tab with the Google Images grid and side panel; `/` focuses the search box.

## Run it

It is a static site. Any web server works:

```sh
git clone https://github.com/justbuildsstuff/Memegle.git
cd Memegle
python -m http.server 8000      # on Windows prefer: python tools/serve.py
```

Open http://localhost:8000. ES modules need a real HTTP origin, `file://` will not work.

## Add your own memes to the repository

1. Drop images into `memes/<folder>/` (JPG, PNG, WEBP, GIF).
2. Run `python tools/build_index.py` (needs Pillow). Existing descriptions and tags are kept.
3. Optional: `python tools/build_index.py --caption` describes new memes with Florence-2 on your
   machine (needs `pip install transformers torch pillow`). Or open the site and use
   "Generate description" / bulk generation in the browser; those edits are stored in the browser
   and can be exported from Settings.
4. Commit and push; GitHub Pages serves the new index.

Memes uploaded through the website never leave the browser. Export/Import in Settings moves a
library between browsers.

## Project layout

```
index.html          shell, loads js/app.js
css/memegle.css     Google-style theme, light + dark tokens
js/app.js           views, routing, actions
js/search.js        BM25, suggestions, did-you-mean, vector ranking
js/store.js         bundled index + IndexedDB uploads/edits/embeddings
js/ai.js            Transformers.js (Florence-2, MiniLM) and OpenAI-compatible provider
data/memes.json     search index for memes/ (generated)
memes/              bundled memes (4 upstream examples + synthetic demo memes)
tools/              build_index.py, make_demo_memes.py, serve.py
```
